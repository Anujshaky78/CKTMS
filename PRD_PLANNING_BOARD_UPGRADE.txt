PRD PENDING · PLANNING BOARD UPGRADE
====================================

KYA BADLA
- PRD Pending ab challan-wise nahi, STORE-WISE dikhta hai (Source + Destination ek row).
- Columns: Source Name | Destination / Store | State | Cluster | Challan PKT | Qty | Value | Last Dispatch | Remarks (vehicle planning)
- Challan PKT = COUNT(DISTINCT challan_no) us store ke liye.
- Store ke aage ▸ dabane par us store ke saare challans (no., barcode, date, division, qty, value) dikhte hain.

REMARKS / VEHICLE PLANNING ENGINE (includes/prd_planner.php)
- Dispatch now : fill kam hai par store overdue hai (critical_days se zyada) -> abhi bhejo
- FTL          : store akela badi gaadi bhar deta hai; zarurat ho to 2 gaadi (jaise 32FT + 14FT)
- Club load    : same source ke paas-paas ke stores (club_radius_km ke andar) ek gaadi me, max 4 stops,
                 shortest route order DC se (4 stops tak exact calculation)
- PTL          : single store, chhoti gaadi, fill theek hai
- Hold         : fill kam aur urgent nahi -> kitne PKT aur chahiye ye bhi batata hai
- Map store    : destination Store Master me nahi mila
- Closed       : store_status closed
- Gaadi size Vehicle Master (vehicle_type, capacity_boxes, value_capacity) se aata hai.
  Master khali ho to config/prd_planning.php ki fallback list use hoti hai.
- Flags: value cap se upar, aaj dispatch day nahi (next day), store lat/long missing,
  source DC master me nahi, kitne din se dispatch nahi hua, lambi store-to-store doori.
- Har store par Planner Note likh sakte hain (auto save, sync ke baad bhi rehta hai).

TOP SUMMARY
- Stores, Challan PKT, Qty, Value, DC-wise distinct challans, already-in-trip challans
- Plan mix bar (click karke filter) + Vehicles needed vs available (Vehicle Master se)

TRIP BANANA (v4: Review plan flow)
- Step 1 Load from Oracle -> Step 2 stores select (row par click, checkbox, ya "Select this load")
  -> Step 3 "Review plan" -> Step 4 "Create N trips".
- Kitne bhi stores aur dono DC ek saath select kar sakte hain. Plan unhe DC-wise, capacity aur
  distance ke hisaab se trips me baantta hai (max_stops per trip).
- Review panel me har trip ka DC aur vehicle badal sakte hain, fill % turant update hota hai,
  stop order aur km dikhte hain, koi trip uncheck karke chhod sakte hain.
- Saare trips ek transaction me bante hain: ek bhi fail ho to koi nahi banta, aur error usi panel me dikhta hai.
- Store Master me nahi / closed stores "left out" list me reason ke saath dikhte hain.

PURANA (v1-v3) TRIP BANANA
- Checkbox se stores chuno ya plan header par "Select this load" dabao.
- Neeche dark bar: selected PKT, value, suggested vehicle aur fill %, warnings.
- Source DC auto-select hota hai (agar source site code/name DC Master se match kare).
- Create trip: route order optimize, stop packet_count = challan PKT,
  har store ka indent PRD-T<tripId>-<stop>, source_ref me challan numbers.
- Trip me gaye challans board se hat jaate hain. Trip CANCEL karne par wapas aa jaate hain.
- Purane build ke PRD-<id> indents automatically link ho jaate hain (double planning nahi hoga).
